# Map Click Button instead of Tip Follow

Tip Follow (Anchor from Route Tip while drawing) was the original #7/#10 plan, but it needs a fragile Host Page “actively extending” signal and fights left-click route drawing. v1 uses **Map Click Button** instead: the rider picks Left or Right in the Extension Popup (default Right) so one button sets the Anchor Point and the other can keep drawing on Strava. Tip Follow stays out of v1; restore only with a new issue and Host Page strategy.
